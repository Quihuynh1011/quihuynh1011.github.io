# Huỳnh Văn Quí — Portfolio

Website portfolio cá nhân của **Huỳnh Văn Quí**, Giám đốc Tài chính (CFO), 15 năm kinh nghiệm.

- Website tĩnh (HTML/CSS/JS), không cần build. Mở `index.html` là chạy.
- Toàn bộ nội dung nằm trong `data/content.js` (song ngữ Việt / Anh).
- Form "Nhà tuyển dụng đăng ký" lưu vào Google Sheets qua Google Apps Script.
- Hướng dẫn chi tiết: [HUONG-DAN.md](HUONG-DAN.md).
